# Visual Plan — episode-007（Gamma production revision）

## Visual system

Gamma Generate、Edit、Share 三段真实产品视频继续承担画面主轴。数字、文章和访谈只做约 1.8 秒的 hash 绑定叠层；叠层退场后立即回到真实操作。创始人访谈页用于人物与来源识别，TechCrunch 同期报道用于历史背景；两者只获准本地 evaluation，最终批准前必须权利终审。

已验证三段 Gamma 官网官方 MP4。已抓取并目检 Sacra 的 Jon Noronha 访谈页和 TechCrunch 2021 年报道页；Gamma 官方长文被 Cloudflare 验证拦截，明确排除，不进入成片。第三方节目视频只完成来源发现，未下载、未剪辑、未渲染。

- Visible action: 成套卡片出现并保持可见。
- Evidence type: product-operation
- Focal crop: Gamma 成品卡片组与单一估值叠层。

- Render target: 市场结果先行
- Claim IDs: claim-gamma-008, claim-gamma-009
