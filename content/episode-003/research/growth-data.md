# Manus 增长与规模口径

研究截止：2026-08-16

## 公司披露

| 指标           | 口径                         | 时间窗                         | 来源                         | 可否入旁白 |
| -------------- | ---------------------------- | ------------------------------ | ---------------------------- | ---------- |
| 虚拟电脑       | 超过 8000 万台               | 上线至 2025-12-17              | 公司公告                     | 可以，需标明公司口径 |
| Tokens         | 超过 147 万亿                | 上线至 2025-12-17 / 12-29      | 公司公告                     | 可以，但本期不必重复 |
| 用户           | 全球数百万                   | 截至 2025-12-29                | 公司 + Meta                  | 可以，不得换算留存 |
| ARR            | 超过 1 亿美元                | 上线八个月，截至 2025-12-17    | 公司自报，CNBC 转述          | 否         |
| 收入 run rate  | 超过 1.25 亿美元             | 截至 2025-12-17                | 公司自报                     | 否         |

## 不能从这些数字推出

- 付费用户、日活、留存、成功任务或人均使用强度。
- 桌面版或 My Computer 带来了增长。
- 加入 Meta 造成了用户接受。
- 虚拟电脑数量等于同时在线用户。

## 本期使用原则

旁白若使用规模，优先用“超过八千万台虚拟电脑”或“数百万用户”，并保留公司/收购方身份。财务数字留在研究包。
