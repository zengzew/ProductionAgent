## Hook 拆分

- **零背景可懂：7 / 8**
  - 第一屏给出“一个 Logo 自己画出来”的具体动作，但首帧先显示已完成 Logo 与说明文字，几何构造动作在第二秒才出现；零背景观众在第一秒看到的是静态结果而非正在发生的动作。
  - 核心信息“AI 画 Logo 的过程被几百万人看过”在 3 秒内出现，来源标签同期显示。
- **继续观看的问题：6 / 7**
  - 20 秒结束时，问题“首日 7 人，为什么后来一天内有一万人来试？”关系到观众是否会信任或使用该产品，而非只问陌生产品为何转型。

## 观众划走风险

### risk-01：首帧动作延迟（medium）
- **时间：** 00:00–00:03
- **观众为什么会走：** 首帧先显示已完成 Logo 与“AI 画 Logo 的完整过程”文字，几何构造动作在第二秒才出现；零背景观众在第一秒看到的是静态成品加一句抽象描述，不是正在发生的具体动作。
- **当前证据：** seg-001 Visual intent 写明“第 0 帧先显示一个已完成 Logo 与‘AI 画 Logo 的完整过程’；画面回到淡色网格，圆出现并锁定……”
- **需要的变化：** 首帧必须直接呈现几何构造动作（网格铺开、圆出现、直线穿过），已完成 Logo 与说明文字在动作开始后 0.5 秒内叠加，不占据第一帧主体。
- **责任角色：** Script Writer

### risk-02：网页/社交/印刷设计只展示静态缩略图（medium）
- **时间：** 00:03–00:10
- **观众为什么会走：** 旁白说“你说需求，它生成 Logo、网页、社交和印刷设计”时，画面只展示一个 Logo 成品放大，随后补出网页、社交、印刷缩略图；缩略图是静态卡片，不是可观察的生成动作，观众看到“说动作却看不到动作”。
- **当前证据：** seg-002 Visual intent：“右侧从空白状态生成一个具体 Logo 成品并放大，随后补出网页、社交、印刷设计缩略图。”
- **需要的变化：** 网页、社交、印刷设计必须各自展示一次从输入到成品的生成过程（可加速），或至少展示一次完整的“输入需求 → 生成非 Logo 设计”动作，使旁白与画面动作匹配。
- **责任角色：** Script Writer

### risk-03：官网主张是文字卡而非用户动作（low）
- **时间：** 00:10–00:18
- **观众为什么会走：** “官网说，不用会设计、也不用反复猜”是文字卡弹出，不是用户动作；观众看到主张声明而非需求被满足的过程。
- **当前证据：** seg-003 Visual intent：“文字卡‘无需设计技能，不用反复猜测’先弹出”。
- **需要的变化：** 文字卡可保留，但必须与一个零设计技能用户的操作画面同步（例如手写需求输入框），使主张与动作绑定。
- **责任角色：** Script Writer

### risk-04：用户评论裁切可能不可读（low）
- **时间：** 00:37–00:45
- **观众为什么会走：** 用户分享帖拼图使用“原文裁切”，若裁切后文字过小或停留时间不足 1.5 秒，观众无法阅读评论内容“设计过程有趣、体验经过打磨”，证据失去可信度。
- **当前证据：** seg-006 Visual intent：“切换为用户分享帖拼图：用户晒出的 Logo 与评论‘设计过程有趣、体验经过打磨’，小字‘ITmedia 观察到用户分享’。”未规定裁切文字大小与停留时间。
- **需要的变化：** 评论文字必须放大至可读尺寸，单条评论停留不少于 1.5 秒；或改为口播读出评论内容，画面同步显示评论原文。
- **责任角色：** Script Writer

## 结论

**REJECT**

总分 87，高于 85 门槛；所有维度得分均高于满分的 60%。但存在 2 条 medium 风险（risk-01、risk-02），违反 seen-action-not-described-action 原则：首帧动作延迟、网页/社交/印刷设计只展示静态缩略图。

退回 Script Writer，修订后必须先重新经过 Oral Judge。

**最小修改清单：**
1. seg-001：首帧直接呈现几何构造动作，已完成 Logo 与说明文字在动作开始后 0.5 秒内叠加。
2. seg-002：网页、社交、印刷设计至少展示一次完整的“输入需求 → 生成非 Logo 设计”动作，使旁白与画面动作匹配。
3. seg-003：文字卡与零设计技能用户的操作画面同步。
4. seg-006：评论文字放大至可读尺寸，单条评论停留不少于 1.5 秒；或改为口播读出评论内容。
