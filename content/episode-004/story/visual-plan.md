# Devin Visual Plan

## Visual system

1080×1920 竖屏以“看得见的自主执行”开场，中段切创始人/演示播放量和获客动作，结尾用资本市场数字卡收住。真实官方视频优先；融资段没有匹配画面时用带来源的数据图形，不回看开场任务。

## Asset summary

真实媒体：官方演示、上手教程、平行 Devin、奔驰访谈。结尾估值用 TechCrunch 口径数据卡。程序化素材只用于数字与来源标签。

## seg-001

- Narrative purpose: 先给执行中的结果。
- Viewer state in: 不认识 Devin。
- Viewer state out: 看懂任务交出去后，它会自己打开浏览器。
- New information: 它自己开始干活。
- Scene structure: 第 0 帧官方演示已在执行中。
- Visual evidence: 持续标“功能演示”与官方来源。
- Animation ideas: 不淡入，浏览器打开保持可见。
- Asset requirements: 已准入官方演示。
- Pacing: 三秒完成交任务到开始干活。
- Visible action: 任务已交出去，浏览器自己打开并开始加载。
- Evidence type: product-operation
- Focal crop: 官方界面中央的任务与浏览器。
- Visual event: 浏览器打开并出现内容。
- Media preference: 官方演示 real-media。
- Render target: hook-delegated-open
- Claim IDs: claim-devin-001

## seg-002

- Narrative purpose: 把动作接到三个奥赛程序员的需求。
- Viewer state in: 看见它自己干活。
- Viewer state out: 知道这是金牌程序员要让它自己干完工程任务。
- New information: 创始人身份与工程师验收。
- Scene structure: 官方演示人物口播收成三名创始人名字，再切回它改代码。
- Visual evidence: 人物与验收动作同屏，不做成静态名片墙。
- Animation ideas: 名字落下后切回执行。
- Asset requirements: 官方演示含创始人口播的片段。
- Pacing: 八秒完成人物到需求。
- Visible action: 名字落下后，代码窗口继续被改写。
- Evidence type: interview
- Focal crop: 人物口播与正在修改的编辑器。
- Visual event: 名字落下后编辑器继续改动。
- Media preference: 官方演示 real-media。
- Render target: hook-founder-need
- Claim IDs: claim-devin-012, claim-devin-009

## seg-003

- Narrative purpose: 用演示播放量打开市场定价问题。
- Viewer state in: 已理解需求。
- Viewer state out: 知道第一批人看见了公开演示，并开始问市场给了什么价。
- New information: 122 万+ 播放量。
- Scene structure: 演示继续跑，播放量数字落下，问题叠上。
- Visual evidence: 播放量与正在工作的浏览器同屏。
- Animation ideas: 数字落下后问题出现。
- Asset requirements: 官方演示 + 播放量图形。
- Pacing: 九秒完成冷启动规模和问题。
- Visible action: 浏览器仍在工作，播放量数字落下。
- Evidence type: product-operation
- Focal crop: 执行区与播放量数字。
- Visual event: 播放量落下后问题出现。
- Media preference: 官方演示 real-media。
- Render target: hook-demo-question
- Claim IDs: claim-devin-015, claim-devin-001

## seg-004

- Narrative purpose: 用种子轮和降价回答怎么让人用得起。
- Viewer state in: 已看见演示被围观。
- Viewer state out: 知道种子轮进来后，个人价格降到 20 美元并可并行。
- New information: 2100 万美元、500 到 20、并行 Devin。
- Scene structure: 种子轮数字落下，价格从 500 收到 20，多个 Devin 并行推进。
- Visual evidence: 媒体/公司标签同屏。
- Animation ideas: 500 划掉、20 落下，并行卡片推进。
- Asset requirements: 官方平行 Devin 视频与价格卡。
- Pacing: 十四秒完成获客门槛。
- Visible action: 价格落下后多个 Devin 同时执行。
- Evidence type: product-operation
- Focal crop: 价格卡与并行会话。
- Visual event: 价格变化后并行卡片推进。
- Media preference: 官方平行 Devin real-media。
- Render target: choice-seed-price-parallel
- Claim IDs: claim-devin-014, claim-devin-005, claim-devin-006

## seg-005

- Narrative purpose: 用企业接受证明有人把大任务交给它。
- Viewer state in: 已理解门槛下降。
- Viewer state out: 知道奔驰把 8 个月压到 8 天，公司自报 89%。
- New information: 奔驰案例与 89%。
- Scene structure: 官方客户访谈收成案例卡，再切 89%。
- Visual evidence: 官方口径标签同屏。
- Animation ideas: 数字依次落下。
- Asset requirements: 官方客户访谈。
- Pacing: 十二秒先案例再自用。
- Visible action: 访谈画面切到 8 天与 89% 落下。
- Evidence type: interview
- Focal crop: 对谈者与案例卡。
- Visual event: 8 天落下后 89% 出现。
- Media preference: 官方客户访谈 real-media。
- Render target: body-acceptance-evidence
- Claim IDs: claim-devin-007, claim-devin-008

## seg-006

- Narrative purpose: 用资本市场证据回答开场问题。
- Viewer state in: 已理解需求和获客。
- Viewer state out: 知道市场给了 25 亿美元估值和超 10 亿美元融资。
- New information: 25 亿估值、超 10 亿融资。
- Scene structure: 估值与融资数字逐个落下，来源条同期出现，停住。
- Visual evidence: TechCrunch 口径标签。
- Animation ideas: 数字落下后停住，不再切回开场。
- Asset requirements: 程序化资本市场数据卡。
- Pacing: 十四秒只回答定价。
- Visible action: 25 亿落下后，超 10 亿融资跟上。
- Evidence type: data-graphic
- Focal crop: 估值与融资两个数字。
- Visual event: 估值落下后融资数字出现。
- Media preference: 无匹配官方视频，使用带来源的数据图形。
- Render target: ending-market-price
- Claim IDs: claim-devin-016
