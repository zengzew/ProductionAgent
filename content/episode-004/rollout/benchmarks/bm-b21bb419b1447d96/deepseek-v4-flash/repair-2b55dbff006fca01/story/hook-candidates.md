# Hook Candidates — Devin

Prepared by Viral Director for episode-004. All quoted claims come from `research/facts.json` with `allowedInNarration=true`; no invented numbers.

## Candidate A (selected): task handoff, browser starts moving itself

### 0–3s first frame

Camera: official demo / overview footage (src-devin-002, src-devin-003). In the first 3 seconds the viewer sees:
- Devin’s task list move from “To do” to “In progress”;
- the built-in browser tab start loading a real GitHub issue page (blank tab → loaded page);
- the page scroll and the cursor enter a code editor field without a human hand.

Synchronous proof: the visible UI changes are the proof the product is acting; the narration carries `claim-devin-001` / `claim-devin-003` / `claim-devin-004`: the official demo shows Devin using its browser, code editor and terminal on its own. The picture does the job of showing action; the narration names the system. No brand homepage screenshot is used as the only proof.

### 3–20s

- Reveal 1: three IOI gold-medal programmers founded Cognition (`claim-devin-012`) and wanted the AI to finish engineering tasks so engineers review the result (`claim-devin-009`). Scott Wu’s sourced line (`claim-devin-013`) explains the olympiad background as an algorithmic-decision advantage.
- Visual: a pull-quote card with the Bloomberg source attribution for `claim-devin-013`; caption “IOI gold medal ×3” for `claim-devin-012`. Moving text must not cover the source line.
- Reveal 2: the official demo is public (video page, upload date 2024-03-12); the play count arrives at 20–32s, not in the hook.
- One open question carried to the end: “What price did the market later put on this AI software engineer?”

### Why this candidate wins

- The first frame has zero background: a browser tab loading and a cursor moving are intelligible without knowing the product.
- It preserves the Director Brief’s reveal order: action → founders → cold start → distribution/acceptance → market pricing.
- It leaves exactly one question that the ending can answer with a sourced valuation.
