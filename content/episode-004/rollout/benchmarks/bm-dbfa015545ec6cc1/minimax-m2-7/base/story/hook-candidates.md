# Hook Candidates — Devin (episode-004)

## Candidate A: The Open Browser

**0–3 s (first frame):** Devin's own cloud IDE is already open. The cursor inside the browser pane moves. A URL field fills. A page begins to load — inside Devin's interface, not a human's.

**Same-3s proof:** POV shot of Devin's UI — terminal pane at bottom, code editor at center, browser pane at top. Everything visible in one frame. No voice, no logo.

**3–11 s narration:** "Three IOI gold medalists built an AI that takes a task — and opens its own browser to get it done."

**11–20 s question:** "The market later put a price on that. What price?"

## Candidate C: The Interface Shows Work in Progress

**0–3 s (first frame):** Devin's interface with a visible task queue. One item shows a progress indicator. Files listed in the editor pane — code being written in real time. The IDE is active; no human hand is visible in frame.

**Same-3s proof:** Frame showing Devin's multi-pane UI — task list, code editor with filenames, terminal. All panes active simultaneously, evidence of parallel work.

**3–11 s narration:** "Three gold medalists made an AI that keeps its own to-do list — and works through it."

## Selected Hook

**Candidate A** — The Open Browser.

**Rationale:** First frame already shows a result (browser open, page loading inside Devin's UI), requires zero background knowledge to read, and the camera sees an action sequence — cursor move, URL fill, page load — not a static screenshot. The proof is a single frame containing all three panes (browser, editor, terminal) with no human input visible. This matches the director-brief beat-01 requirement: "看见任务交出去后，它自己打开浏览器开始干活" with a camera-visible action at 0–3 seconds.
