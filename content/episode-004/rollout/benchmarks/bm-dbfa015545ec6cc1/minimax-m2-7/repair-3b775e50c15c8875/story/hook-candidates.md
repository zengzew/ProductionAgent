# Devin Hook Candidates

## Candidate A — Terminal Cursor (Primary)

**0–3 seconds — Visible result:** A cursor blinks inside Devin's code editor inside Devin's cloud IDE; a file saves automatically; the terminal shows a success message.

**Simultaneous proof:** Camera shows Devin's interface—not a brand homepage—with the editor, terminal, and browser panels all visible and active.

**Why it works:** Zero context needed. Everyone who has coded recognizes this moment: code that runs without you watching it run.

---

## Candidate B — Browser Tab Opens

**0–3 seconds — Visible result:** Devin's built-in browser tab loads a live webpage; the URL bar fills in; the page renders.

**Simultaneous proof:** The browser panel is clearly inside Devin's UI (not a separate Chrome window), with Devin's task-planning sidebar visible alongside it.

**Why it works:** Shows Devin doing web research—the invisible step engineers do constantly but never see the AI do.

---

## Candidate C — Parallel Devins

**0–3 seconds — Visible result:** Three separate Devin windows appear side by side, each with its own IDE, running different tasks simultaneously.

**Simultaneous proof:** Each window shows a different task label and independent progress indicators.

**Why it works:** Visually demonstrates the "parallel Devins" capability (claim-devin-006) in a single frame.

---

## Selected Hook: Candidate A

**Reason:** Terminal cursor is the most universally recognized symbol of "code running on its own." It requires no explanation of what Devin is or who made it—that comes in beat-02. The action is complete in three seconds: something compiled, something ran, without someone holding the keyboard.

**Evidence for gate:**
- claim-devin-001: Devin uses its own browser, code editor, and terminal to act autonomously
- claim-devin-004: Every step is visible in real time
- src-devin-002: Official demo video shows exactly this sequence (cursor, code edit, terminal run)
- src-devin-003: Official tutorial shows the same interface in use

**3-second sequence:**
- Frame 0.0s: Devin's code editor panel fills screen; cursor blinks at end of a function call
- Frame 1.5s: File auto-saves icon flashes; terminal pane shows command running
- Frame 3.0s: Terminal prints success output; task progress indicator updates

**Proof type:** Visible action in Devin's own interface (not a static screenshot, not a brand logo)

**What viewers know by 3 seconds:** "Something just ran on its own in a code editor."

**What viewers are waiting for:** "Who made this, and what did they tell it to do?"
