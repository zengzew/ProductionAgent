## 迁移到本项目的决定

共同结构是一个清楚的结果承诺，接着不断回答具体问题。三片并没有统一的“20 秒 Hook”，
也不是每两秒硬切；实演会连续停留，多句旁白共同解释一次操作。AI 相框更偏体验与
情感，待产清单更偏家庭需求，内容工具更偏高价与成交。新流程允许这些差异。

共同版式把标题、证据、解释和字幕分开。原片和 UI 承担主信息，图表、局部原文承担
数字与获客证据；固定标题没有阻止中部换证据。项目因此保留稳定底盘，把变化集中在
有信息的中部，而不是追求每段换皮或给截图加同一种动画。

写稿前先检查素材，防止口播承诺了“操作”，最终只有首页或概念卡。旁白与画面共同
编辑，但 Fact Guardian 仍独立检查强度、归因和数字。删去机械的二十秒开场、问号
门和长段尾；不迁移创作者特有台词、声音或具体镜头排列。

当前可以据此实现格式与流程。是否达到用户想要的“同样效果”，仍须一条真实新成片
对照观看；不能从三条参考推导成功因果，也不能承诺同等播放量。
